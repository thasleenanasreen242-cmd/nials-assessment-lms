# NiALS Assessment LMS

A responsive assessment-focused learning portal prototype for NiALS Assessment Services.

## Included in this first website preview
- Student dashboard and assessment overview
- Counsellor review workspace
- School administrator aggregate activity dashboard
- NiALS platform administrator overview
- Responsive white and blue visual identity

## Important
This first release is a front-end demonstration using fictional sample data. It does not include authentication, database storage, consent verification, real assessment scoring, or report release controls. Do not enter real student or sensitive personal information.

## Run locally
```bash
npm install
npm run dev
```

## Next implementation stage
Add secure role-based authentication, database schema and row-level security, parental consent workflow, assessment versioning, counsellor review and authorised report release before any real student data is used.
